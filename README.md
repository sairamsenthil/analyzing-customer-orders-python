# Analyzing Customer Orders Using Python

## Project Overview

This project analyzes customer order data for an e-commerce business using Python's built-in data structures and control structures.

The project stores customer and order information using lists, tuples, dictionaries, and sets. It then analyzes customer spending, product categories, purchasing frequency, and customer purchasing patterns to generate useful business insights.

The project was developed as a course-end project to demonstrate practical use of Python data structures, loops, conditionals, list comprehensions, set operations, and sorting.

---

## Project Objectives

The main objectives of this project are to:

* Store and organize customer order information.
* Classify products into different categories.
* Calculate total spending for each customer.
* Classify customers based on their spending.
* Calculate revenue generated by each product category.
* Identify unique products.
* Identify customers who purchased electronics.
* Find the top three highest-spending customers.
* Identify customers purchasing products from multiple categories.
* Find customers who purchased both electronics and clothing.
* Identify frequently purchased products.
* Generate business insights from the analyzed data.

## Data Structures Used

### List

A list is used to store customer names.

```python
customers = [
    "Alice",
    "Bob",
    "Charlie",
    "David",
    "Emma",
    "Frank"
]
```

### Tuple

Each order is stored as a tuple containing:

```text
(customer name, product, price, category)
```

Example:

```python
("Alice", "Laptop", 850, "Electronics")
```

### Dictionary

A dictionary maps each customer to their ordered products.

```python
customer_orders = {
    "Alice": ["Laptop", "T-Shirt"],
    "Bob": ["Headphones", "Jeans"]
}
```

Another dictionary maps products to their categories.

```python
product_categories = {
    "Laptop": "Electronics",
    "T-Shirt": "Clothing"
}
```

### Set

Sets are used to identify unique product categories and unique products and to perform customer set operations.

## Analysis Performed

### 1. Customer Order Analysis

The project calculates the total amount spent by each customer using loops.

Customers are classified as:

* **High-Value Buyer** - spending above $100
* **Moderate Buyer** - spending between $50 and $100
* **Low-Value Buyer** - spending below $50

### 2. Product Category Analysis

Products are classified into:

* Electronics
* Clothing
* Home Essentials

The project calculates the total revenue generated by each category.

### 3. Customer Purchasing Patterns

The project identifies:

* Customers who purchased electronics.
* Customers who purchased products from multiple categories.
* Customers who purchased both electronics and clothing.
* The top three highest-spending customers.

### 4. Product Analysis

The project identifies:

* Unique products.
* Product purchase frequency.
* The most frequently purchased product.

### 5. Dictionary Operations

Dictionary methods are demonstrated for retrieving and modifying customer records using methods such as:

* `get()`
* `setdefault()`
